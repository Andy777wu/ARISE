# ARISE V1 需求文档

> 项目名称：ARISE — Asset Rising Intelligence & Strategy Engine  
> 版本：V1  
> 更新日期：2026-08-14  
> 文档状态：已全部确认，可直接交付 UI 设计与开发。

---

## 1. 项目范围

### 1.1 V1 核心功能
- **用户体系**：注册、登录（验证码）、登录态保持
- **家庭空间**：创建、邀请、成员管理、数据共享与权限控制
- **资产/负债管理**：手动录入、编辑、多级分类、拆分与合并分类
- **数据可视化**：家庭/个人总览、资产与负债趋势、桑基图（水平）

### 1.2 V1 不包含
- 行情、策略引擎、价格警报、报告导出、自动获取价格
- Excel/CSV 导入导出
- 还款计划
- 非人民币资产
- 移动 App 独立开发（Web 适配 H5）
- 密码设置与找回功能

## 2. 用户体系

### 2.1 注册
- **方式**：手机号或邮箱 **二选一** + 图片验证码 + 短信/邮箱验证码
  - 用户输入手机号或邮箱，完成图片验证码（人机校验）
  - 系统向对应手机号发送短信验证码，或向邮箱发送邮件验证码
  - 用户输入验证码，验证通过后完成注册
- 注册成功后自动登录并进入个人空间，可创建或加入家庭空间
- **不设置密码**，所有登录均通过验证码完成

### 2.2 登录
- **方式**：手机号或邮箱 **二选一** + 图片验证码 + 短信/邮箱验证码
  - 用户输入手机号或邮箱，完成图片验证码
  - 系统发送短信/邮箱验证码
  - 用户输入验证码，验证通过后登录
- 单设备登录：新设备登录后，旧设备登录状态失效
- 登录态保持：登录成功后 **24 小时** 内有效，超时需重新登录

### 2.3 验证码规则
- 短信/邮箱验证码：**5 分钟有效**
- 发送间隔：同一用户 **60 秒** 内不可重复发送
- **防爆破**：
  - 必须通过图片验证码校验后才能发送短信/邮箱验证码
  - 单日验证码发送次数上限（建议 10 次/日）
  - 登录/注册请求需进行 IP 限流
  - 连续验证失败达到阈值（如 5 次）后锁定一段时间（如 15 分钟）

### 2.4 忘记密码
- **无此功能**，已移除

## 3. 家庭空间与成员管理

### 3.1 创建家庭空间
- 第一个用户创建家庭空间，成为创建者
- 创建后可邀请已注册用户加入

### 3.2 邀请成员
- **仅创建者可邀请**
- 通过手机号邀请，需对方已注册
- 被邀请人收到站内信通知，点击“同意”后加入家庭空间

### 3.3 成员管理
- **角色**：创建者、普通成员
- **操作**：
  - 移除成员（仅创建者可操作）
  - 成员主动退出家庭空间
  - 转让创建者身份（仅创建者可转让）
- 成员加入后保留个人空间，可切换“个人总览”和“家庭总览”，默认家庭总览

### 3.4 数据删除规则（成员退出/被移除）
- 成员被移除或主动退出家庭空间时，**该成员在家庭空间内创建的所有资产/负债条目将被删除**
- 该成员个人空间中的数据不受影响，仍保留
- 家庭总览不再包含该成员的数据
- **若该成员名下的分类因此变为空（即该分类下没有任何资产/负债条目），则自动删除该空分类**

### 3.5 数据可见性
- 数据有归属人，但汇总到家庭总览
- 默认成员只能查看家庭汇总，不能查看其他成员明细
- 成员可自行开放自己的明细给其他成员查看（可配置）

### 3.6 分类共享
- 家庭空间共享一套分类体系
- 一人修改分类，所有成员可见

## 4. 资产与负债管理

### 4.1 资产/负债条目字段
| 字段 | 说明 |
|------|------|
| 名称 | 如“招商银行活期” |
| 类别 | 关联多级分类，必选最后一级分类 |
| 金额 | 当前金额，手动录入 |
| 账户类型 | 自定义，默认：银行存款、股票、基金，支持修改 |
| 备注 | 可选 |
| 创建时间 | 系统自动记录 |
| 记账日期 | 手动选择，用于数据可视化 |

### 4.2 数据录入与快照
- 全部手动录入
- 修改金额时只能修改当前金额，系统自动记录修改当天数据（以天为维度）
- 一天内多次修改，以当天最后一次变更结束时的数据作为历史记录
- 历史数据只记录有变更日期的值，没有记录的天不显示（不自动沿用前一天）

### 4.3 多级分类
- 支持多级分类（示例：基金 → 支付宝/微信）
- 分类不可自定义排序，按创建时间固定排列
- 删除一级分类时，其二级分类自动提升为一级分类

### 4.4 拆分分类
- **仅最后一级子分类可拆分**
- 操作步骤：
  1. 选择最后一级子分类进入详情页
  2. 点击“拆分”按钮
  3. 页面上出现一个输入卡片，输入新分类名称和金额
  4. 点击加号按钮，可新增多个输入卡片（可添加多个子分类）
  5. 确认拆分时，系统校验：**所有新子分类金额之和必须等于原分类金额**
     - 若不等，拆分失败，页面提示“原分类剩余金额：XX 元”，用户需调整输入
     - 若相等，拆分成功，原分类删除，资产条目按输入金额分配到新子分类
- 不支持未分配金额自动归入“其他”

### 4.5 合并分类
- 操作步骤：
  1. 选择两个或多个分类
  2. 指定合并后的新分类名称
  3. 确认后，原分类删除，所有资产条目归入新分类
- 不允许撤销合并

## 5. 数据可视化

### 5.1 总览页面
- 分为“家庭总览”和“个人总览”，默认家庭总览
- **个人总览与家庭总览展示逻辑一致**，区别仅在于数据范围：
  - 个人总览展示当前用户自己的数据
  - 家庭总览汇总所有家庭成员的数据

#### 家庭总览
- 展示：净资产、净资产月度变化
- 成员数量、**每个成员的净资产及净资产月度变化**（展示所有成员的）
- 桑基图（**水平方向**）：
  - **资产部分**：从“家庭总资产”水平流向各资产分类
  - **负债部分**：从“家庭总负债”水平流向各负债分类
  - **资产和负债分开展示**
  - 支持金额或百分比展示
  - 资产和负债分开展示（建议上下或切换展示）

#### 个人总览
- 展示：净资产、净资产月度变化（当前登录成员自己的）
- 桑基图（水平方向）：展示个人资产分类层级（不包含负债部分，负债以数值形式体现在净资产中）

### 5.2 月度变化定义
- **净资产月度变化**：当前月末净资产相较于上月末净资产的增减额（或百分比）
- 展示方式：可显示为“+XX 元”或“-XX 元”，并标注涨跌色

### 5.3 趋势图
- 展示内容：总资产、总负债、净资产，以及各类别资产/负债的时间趋势
- 图表类型：柱状图
- 时间维度：按月/年切换
- 数据来源：系统记录的每日快照（仅变更日有数据）

### 5.4 分类详情页
- 展示该分类下所有资产条目列表
- 不展示该分类的变动趋势

## 6. 信息架构与页面流程

### 6.1 主要页面
1. 登录/注册（验证码流程）
2. 家庭空间管理（创建/加入、成员管理、邀请）
3. 总览页（家庭/个人切换，净资产、趋势图、桑基图）
4. 资产/负债列表（可按成员、分类筛选）
5. 资产/负债新增/编辑页
6. 分类管理页（多级分类、拆分、合并）
7. 站内信/通知页（邀请通知）
8. 设置页（个人资料、退出家庭空间、开放明细设置等）

### 6.2 关键用户流程
- **新用户流程**：注册（手机/邮箱验证）→ 登录 → 创建/加入家庭空间 → 添加资产/负债 → 查看总览
- **家庭协作流程**：创建者邀请成员 → 成员站内信同意 → 各自录入数据 → 汇总到家庭总览
- **分类调整流程**：进入分类管理 → 拆分/合并分类 → 系统重新归类资产 → 总览更新

## 7. 数据模型（核心表）

### 7.1 用户表
- 用户ID、手机号（可空）、邮箱（可空）、创建时间
- 至少绑定一种联系方式（手机号或邮箱），用于登录验证码

### 7.2 家庭空间表
- 家庭ID、名称、创建者ID、创建时间

### 7.3 家庭成员表
- 家庭ID、用户ID、角色（创建者/成员）、是否开放明细、状态（正常/已退出/已移除）、加入时间

### 7.4 分类表
- 分类ID、家庭ID、父分类ID、名称、创建时间
- 父子关系形成多级树，按创建时间排序

### 7.5 资产/负债条目表
- 条目ID、用户ID、家庭ID、分类ID（最后一级）、名称、金额、账户类型、备注、创建时间、记账日期

### 7.6 数据快照表
- 快照ID、条目ID、金额、记录日期（天）
- 每次修改金额时插入/更新当天快照（以当天最后一次为准）

### 7.7 通知表
- 通知ID、接收用户ID、类型（邀请）、内容、状态（已读/未读）、创建时间

## 8. 非功能需求

- **平台**：Web 端，适配 H5（响应式，兼容移动浏览器）
- **安全**：全站 HTTPS，验证码传输加密，防爆破限流
- **登录控制**：单设备登录，新登录踢下线，登录态保持 24 小时
- **数据隔离**：家庭数据按家庭ID隔离，个人数据按用户ID隔离
- **性能**：总览页面加载流畅，支持家庭规模数据量（建议首屏 < 2 秒，图表交互 < 200ms）

---

## 9. 验收标准

- 用户可通过手机号或邮箱注册、登录，使用验证码完成身份校验
- 验证码有防爆破、有效期限和发送间隔控制
- 创建者可邀请成员，成员同意后加入家庭空间
- 成员退出或被移除后，其家庭空间数据删除，个人数据保留
- 资产/负债可手动新增、编辑、删除，并关联多级分类
- 分类支持拆分和合并，拆分时金额必须匹配，否则失败
- 家庭/个人总览正确展示净资产、月度变化、成员数据、桑基图（水平）
- 趋势图按日快照生成，支持月/年切换
- 多级分类删除一级后二级自动提升
- 单设备登录生效，新登录踢下线
- 全站 HTTPS，数据隔离正确
