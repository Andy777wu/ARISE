# ARISE V1 UI 设计说明（UI-DESIGN）

> 项目名称：ARISE — Asset Rising Intelligence & Strategy Engine  
> 版本：V1  
> 更新日期：2026-08-15  
> 用途：本文档作为 **Stitch 生成 UI 的设计规格**，逐页描述布局、元素、交互与状态。  
> 说明：V1 无密码、无独立注册页，首次登录自动注册；Web H5 移动端优先。

---

## 1. 设计基调（全局统一）

- **应用定位**：家庭/个人资产管理工具，风格应**简洁、清爽、可信赖**，弱化金融焦虑感。
- **主色**：品牌蓝（建议 `#1677FF` 系，与 Ant Design 主色一致），用于主按钮、激活态、链接。
- **涨跌色**：遵循中国习惯——**涨=红（`#F5222D`）**，**跌=绿（`#52C41A`）**；用于净资产月度变化标注。
- **中性色**：背景浅灰 `#F5F6F7`，卡片/内容区纯白 `#FFFFFF`，主文字 `#1F2329`，次要文字 `#646A73`，辅助 `#8F959E`。
- **圆角**：卡片 12px，按钮 8px，输入框 8px。
- **间距体系**：页面左右边距 16px，卡片间距 12px。
- **布局**：移动端 H5 优先，单列纵向布局；底部固定 Tab 栏（总览 / 资产 / 分类 / 我的）；顶部导航栏（返回、标题、右侧操作）。
- **图表风格**：桑基图与柱状图配色从主色衍生（蓝色系渐变 + 辅助色），圆角端点，无网格线或浅网格，金额/百分比标注清晰。

## 3. 页面 UI 规格

### P01 登录页（LoginPage）

**页面目标**：手机号或邮箱 + 图片验证码 + 短信/邮箱验证码完成登录；首次登录自动注册，无密码、无忘记密码、无独立注册页。

**布局结构（自上而下）**：
1. 顶部品牌区：应用 Logo（圆形图标）+ 应用名「ARISE」+ 副标语「家庭资产管理」
2. 登录表单卡片（白色圆角卡片）：
   - 联系方式输入框：占位「请输入手机号或邮箱」，自动识别手机号/邮箱格式
   - 图片验证码行：验证码输入框（占位「图形验证码」）+ 右侧验证码图片（可点击刷新，变形字体图片）
   - 短信/邮箱验证码行：验证码输入框（占位「请输入验证码」，4~6 位数字）+ 右侧「获取验证码」按钮（发送后 60s 倒计时灰显「60s 后重发」）
3. 主操作：「登录」按钮（全宽、主色填充、圆角）
4. 底部提示文案：「首次登录将自动注册，登录即代表同意《用户协议》和《隐私政策》」灰色小字

**交互说明**：
- 输入联系方式并点击「获取验证码」→ 校验图片验证码 → 通过后发送短信/邮箱验证码，按钮进入 60s 倒计时
- 图片验证码错误/过期：toast 提示「验证码错误，请重试」并刷新图片
- 点击「登录」→ 校验短信/邮箱验证码 → 成功进入主界面（个人空间/家庭空间）
- 登录成功且为首次注册时，toast「欢迎加入 ARISE」；已注册用户直接进入
- 输入格式错误、验证码错误、发送频繁、操作锁定等错误均以 toast 或输入框下方红字提示

**关键状态**：默认态 / 倒计时态 / 校验失败态（图片验证码错误、验证码错误）/ 锁定态（15 分钟）。

### P02 家庭空间管理页（FamilyManagePage）

**页面目标**：创建家庭空间、管理成员（邀请/移除/转让）、退出家庭。无家庭时展示创建引导。

**布局结构**：
1. 顶部导航栏：标题「家庭空间」，右侧「邀请」按钮（有家庭且为创建者时显示）
2. 场景 A（无家庭）：
   - 空状态插画 + 文案「创建一个家庭空间，与家人共享资产管理」
   - 「创建家庭空间」主按钮 → 弹出输入框（家庭名称）→ 确认创建
3. 场景 B（已有家庭）：
   - 家庭信息卡片：家庭名称、创建时间、成员数量
   - 「成员」区块标题 + 成员列表：
     - 每行：成员头像（首字母圆形头像）、昵称/联系方式、角色标签（「创建者」主色描边标签 / 「成员」灰色标签）、右侧操作
     - 创建者对成员行显示「移除」操作（红字，弹确认框）
     - 创建者对自身行显示「转让创建者」操作
   - 底部操作区：「退出家庭空间」红色文字按钮（二次确认弹窗）

**交互说明**：
- 邀请：点击「邀请」→ 弹窗输入被邀请人手机号 → 确认发送 → toast「邀请已发送，等待对方同意」
- 移除成员：二次确认弹窗提示「移除后，该成员在本家庭的数据将被删除，是否继续？」→ 确认后移除
- 转让创建者：确认弹窗提示「转让后您将成为普通成员」→ 确认后角色互换
- 退出家庭：二次确认弹窗提示数据删除规则 → 确认后退出并返回个人空间

**关键状态**：无家庭引导态 / 成员列表态 / 邀请弹窗 / 确认弹窗。

### P03 总览页（OverviewPage）

**页面目标**：展示家庭/个人净资产、净资产月度变化、成员净资产与水平桑基图。

**布局结构（自上而下）**：
1. 顶部导航栏：左侧当前家庭名（点击可切换家庭），右侧通知图标（未读红点）
2. 范围切换：分段控制器（Segmented）「家庭总览 / 个人总览」，默认家庭总览
3. 净资产概览卡片（主色渐变背景）：
   - 标题「净资产」
   - 大号金额（如 ¥1,234,567.89，千分位）
   - 月度变化行：「较上月」+ 红/绿色「+¥12,345（+1.2%）」或「-¥5,000（-0.5%）」
   - 家庭模式下附「成员 3 人」标签
4. 成员净资产列表（仅家庭模式，每人一行卡片）：
   - 头像、昵称、角色标签、净资产金额、月度变化（红/绿）
5. 桑基图区块（卡片）：
   - 标题「资产分布」，右上角展示切换「金额 / 百分比」
   - 水平桑基图（资产）：左侧源节点「家庭总资产」→ 水平流向各一级分类 → 细分到二级分类
   - 标题「负债分布」+ 独立一张水平桑基图：源节点「家庭总负债」→ 流向各负债分类
   - 节点色：资产用蓝色系，负债用橙红色系；节点显示名称与金额/百分比
   - 个人总览模式：仅展示「资产分布」桑基图（不展示负债图）

**交互说明**：
- 切换「家庭/个人」：数据范围刷新
- 切换「金额/百分比」：桑基图标注与流量宽度联动
- 点击桑基图分类节点：跳转该分类详情页（P07）
- 点击成员行（家庭模式）：如该成员已开放明细，可进入查看其条目列表

**关键状态**：加载骨架屏 / 空数据（无资产时展示「去添加第一笔资产」引导按钮）/ 有数据态。

### P04 趋势页（TrendPage）

**页面目标**：以柱状图展示总资产、总负债、净资产随时间（月/年）的变化趋势。

**布局结构**：
1. 顶部导航栏：返回 + 标题「趋势」，右侧范围切换（家庭/个人）
2. 粒度切换：分段控制器「按月 / 按年」
3. 图例行：三个色块（总资产-蓝 / 总负债-橙 / 净资产-绿）+ 文字
4. 柱状图卡片（D3）：
   - X 轴：时间（按月为「2026-08」，按年为「2026」）
   - Y 轴：金额（千分位缩写，如 10万）
   - 三组柱子并排或分组展示，悬停显示具体数值 Tooltip
   - 仅展示有快照记录的日期点（无记录的天不显示）
5. 空状态：无数据时展示「暂无趋势数据」插画

**交互说明**：
- 切换月/年、切换家庭/个人：图表刷新
- 悬停/点击柱子：Tooltip 显示「2026-08：总资产 ¥XXX，总负债 ¥XXX，净资产 ¥XXX」

### P05 资产/负债列表页（AssetListPage）

**页面目标**：查看、筛选、新增、编辑、删除资产/负债条目。

**布局结构**：
1. 顶部导航栏：标题「资产」，右侧「+」新增按钮
2. 筛选栏：两个下拉筛选——「成员」（家庭模式，默认全部/我）与「分类」（分类树级联选择）
3. 统计摘要行（可选）：当前筛选下的资产总额 / 负债总额
4. 条目列表（卡片式，按分类或成员分组）：
   - 每行：条目名称、分类标签（如「基金 > 支付宝」）、账户类型小字、金额（右对齐、加粗）、记账日期小字
   - 资产金额黑色/蓝色，负债金额红字（由分类属性决定）
5. 底部浮动按钮（FAB）：「+ 添加资产/负债」主色圆形按钮
6. 空状态：插画 + 「还没有资产记录，点击右下角添加」

**交互说明**：
- 点击条目行 → 进入编辑页（P06）
- 长按条目或滑动条目 → 出现「删除」操作 → 二次确认弹窗
- 筛选变更 → 列表刷新；明细权限：默认只展示本人条目与已开放成员的条目
- 点击 FAB → 进入新增页（P06）

### P06 资产/负债新增编辑页（AssetEditPage）

**页面目标**：新增或编辑一条资产/负债记录。

**布局结构**：
1. 顶部导航栏：返回 + 标题（新增：「添加资产/负债」；编辑：条目名称），右侧「保存」
2. 表单（白色卡片，竖向排列，每个字段带左侧标签）：
   - 名称（必填）：输入框，占位「如：招商银行活期」
   - 分类（必填）：级联选择器（P icker），展示「一级 > 二级 > 末级」路径，**只能选择最后一级分类**，占位「请选择分类」
   - 金额（必填）：数字输入框，前缀「¥」，千分位，小数 2 位，占位「0.00」
   - 账户类型：选择器，默认选项「银行存款 / 股票 / 基金」，支持「自定义」输入
   - 记账日期：日期选择器，默认今天
   - 备注（选填）：多行文本输入，占位「备注信息（选填）」
3. 底部：主按钮「保存」（全宽）
4. 编辑模式额外项：页面底部「删除此条目」红色文字按钮（二次确认）

**交互说明**：
- 分类必须为末级，否则保存按钮置灰或提示「请选择最后一级分类」
- 金额校验：必须大于 0 的数字
- 保存成功 → toast「已保存」→ 返回列表/详情
- 删除 → 二次确认弹窗 → 删除后返回列表

### P07 分类详情页（CategoryDetailPage）

**页面目标**：查看某分类下的资产条目列表；末级分类可发起拆分。

**布局结构**：
1. 顶部导航栏：返回 + 分类名称
2. 分类汇总卡片：分类名称、该分类下资产总金额、父级路径（如「基金 > 支付宝」）
3. 操作区（仅末级分类显示）：「拆分分类」按钮（主色）
4. 条目列表：名称、账户类型、金额、记账日期
5. 拆分弹窗（全屏弹窗或底部弹层）：
   - 顶部标题「拆分分类」
   - 原分类信息行：「原分类金额：¥XXX」
   - 动态输入卡片列表（每张卡片）：
     - 新分类名称输入框（必填）
     - 分配金额输入框（数字，前缀 ¥）
     - 卡片右上角「删除」图标（至少保留一张）
   - 底部「+ 添加子分类」虚线加号按钮
   - 实时合计行：「已分配 ¥XXX / 原分类金额 ¥XXX」+ 剩余金额提示
   - 底部主按钮「确认拆分」（金额不匹配时置灰并显示提示「原分类剩余金额：¥XXX」）

**交互说明**：
- 点击「拆分分类」→ 打开拆分弹窗，默认一张空输入卡片
- 点击「+ 添加子分类」→ 新增一张卡片（可多张）
- 金额实时校验：所有新子分类金额之和必须等于原分类金额；不匹配时按钮禁用并提示剩余金额
- 确认拆分成功 → 关闭弹窗，分类被替换为新子分类，条目按金额重新分配 → toast「拆分成功」

### P08 分类管理页（CategoryManagePage）

**页面目标**：管理家庭共享的多级分类（新增、重命名、删除、合并、进入拆分）。

**布局结构**：
1. 顶部导航栏：标题「分类管理」，右侧「合并」按钮
2. 工具栏：「+ 新增分类」按钮（主色）
3. 分类树（缩进层级列表）：
   - 一级分类：分类名 + 子级数量 + 右侧操作（「+」新增子分类 / 更多）
   - 二级及以下：缩进显示分类名 + 金额汇总 + 右侧操作
   - 每行：分类名称、该分类下资产总额小字
   - 末级分类行有「拆分」入口
4. 合并模式（点击「合并」进入）：
   - 顶部提示「请选择要合并的分类（2 个及以上）」
   - 每行出现多选复选框，选中行高亮
   - 底部弹出「合并为新分类」输入框 + 确认按钮
   - 确认前二次确认弹窗：「合并后原分类将被删除，不可撤销」

**交互说明**：
- 新增分类：选择父级（不选则创建一级）→ 输入名称 → 确认
- 重命名：点击「重命名」→ 输入框弹窗 → 确认
- 删除：弹窗提示——若为一级分类「删除后其二级分类将自动提升为一级」→ 确认
- 拆分：仅末级分类显示「拆分」→ 跳转分类详情页（P07）发起
- 合并：选择多个分类（须同层级）→ 输入新名称 → 二次确认 → 完成合并

### P09 通知页（NotificationPage）

**页面目标**：查看站内信（邀请通知），处理同意/拒绝邀请。

**布局结构**：
1. 顶部导航栏：返回 + 标题「通知」
2. 通知列表（卡片式，未读行左侧或顶部红点）：
   - 图标（邀请类：家庭图标）
   - 标题（如「张三 邀请您加入家庭」）
   - 内容摘要（如「家庭：我的家」）
   - 时间（相对时间，如「5 分钟前」）
   - 状态标签：未读（红点）/ 已处理（灰字「已同意」/「已拒绝」）
3. 邀请类通知操作区（未处理时显示两个按钮）：「同意」主色 /「拒绝」描边
4. 空状态：插画 + 「暂无通知」

**交互说明**：
- 点击未读通知 → 标记已读
- 点击「同意」→ 加入家庭 → toast「已加入家庭」→ 可跳转家庭空间
- 点击「拒绝」→ 状态更新为已拒绝
- 重复处理同一邀请：幂等，已处理后按钮不再显示

### P10 设置页（SettingsPage / 我的）

**页面目标**：个人资料、明细开放设置、当前家庭、退出家庭、退出登录。

**布局结构**：
1. 顶部导航栏：标题「我的」
2. 用户信息卡片：头像（首字母圆形）、昵称（联系方式展示名）、联系方式小字；右侧「编辑」→ 修改昵称弹窗
3. 设置分组列表（Ant Design Cell 分组卡片）：
   - 分组「隐私」：
     - 开关「向家庭成员开放我的明细」（Switch，描述「开启后其他成员可查看您的资产明细」）
   - 分组「家庭」：
     - 行「当前家庭」→ 显示家庭名称，点击进入家庭管理（P02）
     - 行「退出家庭空间」→ 红色文字，点击二次确认
   - 分组「账号」：
     - 行「退出登录」→ 红色文字，点击确认后清除登录态返回登录页
4. 版本信息页脚：「ARISE V1.0.0」

**交互说明**：
- 修改昵称：弹窗输入 → 保存 → 刷新显示
- 明细开关：切换即时生效，toast 反馈
- 退出家庭：二次确认弹窗提示「退出后您在本家庭的数据将被删除」→ 确认后退出
- 退出登录：二次确认 → 清除 Token → 跳转登录页（P01）

## 4. 交付 Stitch 的生成建议
